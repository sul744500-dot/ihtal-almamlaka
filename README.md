# احتلّ المملكة 👑

لعبة مسابقات سعودية تعمل بالكامل في المتصفح: الفريق الأحمر ضد الفريق الأزرق على احتلال 25 منطقة من مدن المملكة، مع **شاشة جمهور** نظيفة للتصوير و**لوحة تحكم سرية للمقدم**، ومؤثرات وأصوات بأسلوب برامج المسابقات التلفزيونية.

- React 19 + TypeScript + Vite + Tailwind CSS 4
- واجهة عربية كاملة RTL، بخطوط Cairo وReem Kufi وLalezar (مضمّنة، تعمل دون إنترنت)
- الحفظ محليًا في IndexedDB (المباريات، سجل التراجع، الأسئلة، الإعدادات) — بدون تسجيل دخول
- تطبيق PWA قابل للتثبيت ويعمل دون اتصال
- 251 سؤالًا عربيًا في 8 فئات وبثلاثة مستويات، مع محرر أسئلة واستيراد/تصدير JSON وCSV

## التشغيل على جهازك

**الأسهل (ويندوز):** انقر نقرًا مزدوجًا على الملف `تشغيل اللعبة.bat`. سيثبّت الحزم أول مرة، ثم يبني اللعبة ويشغّل **خادم المزامنة** ويفتح لوحة المقدم على:

```
http://localhost:8787/#/host
```

اترك نافذة الخادم السوداء مفتوحة أثناء اللعب؛ فيها روابط OBS والجوال ورمز QR.

**يدويًا (أي نظام):** يتطلب Node.js 20.19 أو أحدث.

```bash
npm install
```

```bash
npm start
```

`npm start` يبني اللعبة ثم يشغّل الخادم على المنفذ 8787 (لتغييره: متغير البيئة `IHTAL_PORT`، ولتثبيت رمز الجوال: `IHTAL_PIN`). للتطوير مع التحديث الفوري استخدم `npm run dev` (العنوان `http://localhost:5173`).

### الروابط المباشرة

| الصفحة | الرابط |
| --- | --- |
| الرئيسية | `/#/` |
| إنشاء مباراة (3 خطوات) | `/#/new` ← `/#/new/teams` ← `/#/new/categories` |

## التصوير في OBS

### الطريقة المفضلة: Browser Source (عبر خادم المزامنة)

1. شغّل اللعبة عبر `تشغيل اللعبة.bat` (أو `npm start`) وافتح لوحة المقدم `http://localhost:8787/#/host`.
2. في OBS أضف **Browser Source** بالرابط:
   ```
   http://localhost:8787/?obs=1#/audience
   ```
   بعرض **1920** وارتفاع **1080**، وفعّل «Control audio via OBS» لالتقاط المؤثرات الصوتية.
3. الإضافة `?obs=1` تعطي صورة نظيفة: لا أزرار ولا رسالة «تفعيل الصوت» ولا تنبيهات.
4. الرابط موجود أيضًا في زر «📱 الجوال وOBS» في لوحة المقدم مع زر نسخ.

### طريقة بديلة: نافذة المتصفح

1. اضغط «📺 شاشة الجمهور» في لوحة المقدم لفتحها في نافذة مستقلة، واسحبها إلى الشاشة الثانية.
2. انقر فيها مرة لتفعيل الصوت، ومرتين للملء الكامل، ثم استخدم **Window Capture** في OBS.
3. لا تصغّر النافذة (Minimize)؛ المتصفح يوقف الرسوم المتحركة في النوافذ المخفية.

الأصوات تصدر من شاشة الجمهور فقط افتراضيًا حتى لا تتكرر في التسجيل. الشاشة مصممة بدقة ثابتة 1920×1080 وتتكيف مع أي حجم.

## التحكم من الجوال

1. شغّل الخادم كما سبق، ثم اضغط «📱 الجوال وOBS» في لوحة المقدم على الكمبيوتر.
2. امسح رمز QR بكاميرا الجوال (يجب أن يكون الجوال على **شبكة الواي فاي نفسها**). يفتح الرابط لوحة المقدم على الجوال.
3. الرابط يحتوي **رمز PIN** من 4 أرقام يتغير عند كل تشغيل للخادم؛ لا يستطيع أي جهاز آخر على الشبكة التحكم دونه. الأجهزة على الكمبيوتر نفسه (المتصفح وOBS) لا تحتاج رمزًا.
4. أول مرة قد يسألك ويندوز عن السماح لـ Node.js عبر جدار الحماية: اختر **الشبكات الخاصة**.

كيف يعمل التزامن:
- كل الشاشات تتصل بالخادم عبر WebSocket، والخادم يحتفظ بآخر حالة للمباراة فتظهر فورًا لأي شاشة تتصل لاحقًا (مثل OBS بعد بدء المباراة).
- تُصحَّح فروق الساعة بين الجوال والكمبيوتر تلقائيًا حتى يعدّ المؤقت بدقة على كل الشاشات.
- عند وجود أكثر من لوحة تحكم، تتولى لوحة الكمبيوتر الأمور التلقائية (انتهاء الوقت، عجلة الحظ) واختيار الأسئلة، فتُستخدم أسئلة الكمبيوتر وسجل استخدامها حتى عند الضغط من الجوال.
- إذا انقطع الخادم أو أُعيد تشغيله، تعيد الشاشات الاتصال وتتزامن تلقائيًا، والمباراة محفوظة في الكمبيوتر.
- بدون الخادم (مثلًا عند النشر على رابط عام) يبقى التزامن بين نوافذ المتصفح نفسه عبر `BroadcastChannel`.

## قواعد اللعب (قابلة للتعديل)

- **الجولة** = دور لكل فريق، فعدد الأسئلة متساوٍ دائمًا. الافتراضي 20 جولة (40 سؤالًا) و15 ثانية للإجابة.
- يختار الفريق منطقة **محايدة للاحتلال** أو **منطقة للخصم للهجوم**؛ الإجابة الصحيحة تمنحه المنطقة.
- المنطقة العادية = نقطة، **الذهبية ⭐** = نقطتان وتمنح قدرة خاصة عند أول احتلال لها.
- أسئلة الهجوم والذهبي أصعب بمستوى، والصعوبة تتصاعد مع تقدم المباراة (يمكن تثبيتها).
- **حصانة بعد السرقة 🔒**: لا تُسترجع المنطقة المسروقة في الدور التالي مباشرة (يمنع تبادل السرقة بلا نهاية).
- **القدرات** (حد أقصى لكل فريق): 🛡️ درع لجولتين، ⏱️ وقت إضافي، ✂️ حذف إجابتين، 🔁 فرصة ثانية.
- **منطقة التاج 👑** في المنتصف تُفتح في آخر الجولات وتساوي 3 نقاط.
- **عجلة الحظ 🎡** تدور للفريق المتأخر كل عدة جولات، و**الأحداث المفاجئة ⚡** محدودة العدد (افتراضيًا حدثان).
- **الجولة النهائية الحاسمة**: تسقط كل الدروع وكل سرقة ناجحة تمنح نقطة إضافية.
- **الريمونتادا 🔥**: احتفال خاص عندما يقلب فريق تأخرًا بثلاث نقاط أو أكثر.
- النقاط تُحسب دائمًا من ملكية المناطق + النقاط الإضافية، فلا يمكن أن تختلف عن اللوحة.
- عند التعادل **جولة فاصلة**: سؤال للفريقين وأول إجابة صحيحة تحسم بنقطة.

## النشر على رابط عام (لاحقًا)

المشروع جاهز للاستضافة الثابتة (Static) لأنه يستخدم روابط `#` ومسارات نسبية:

- **Netlify:** اربط المستودع (الإعدادات في `netlify.toml`)، أو اسحب مجلد `dist` بعد `npm run build` إلى Netlify Drop.
- **Vercel:** استورد المستودع (الإعدادات في `vercel.json`).
- **GitHub Pages / Cloudflare Pages:** انشر محتوى مجلد `dist`.

يلزم HTTPS لتثبيت التطبيق (PWA) على الأجهزة الأخرى. بيانات كل مستخدم تبقى في متصفحه فقط.

```
src/lib/engine.ts        محرك اللعبة (دالة نقية + بذور عشوائية قابلة للإعادة)
src/lib/questions/       بنك الأسئلة والتحقق منه
relay/server.mjs         خادم المزامنة المحلي (يقدّم اللعبة + WebSocket + رمز PIN)
src/lib/sync.ts          التزامن بين الشاشات (BroadcastChannel + WebSocket، مع منع التكرار)
src/lib/relay.ts         الاكتشاف التلقائي للخادم والاتصال به
src/lib/clock.ts         ساعة مشتركة تصحح فرق التوقيت بين الأجهزة
src/lib/db.ts            التخزين في IndexedDB والنسخ الاحتياطي
src/lib/sound.ts         مؤثرات صوتية مولّدة بـ Web Audio (بدون ملفات)
src/store/               مخازن الحالة (المباراة، الإعدادات، المؤثرات، المسودة)
src/components/stage/    شاشة الجمهور (اللوحة، السؤال، الإعلانات، العجلة، الفائز)
src/components/host/     لوحة تحكم المقدم
src/pages/               الصفحات العشر
```
